# 福建契约文书：土地类型、交易与历史背景

对课程资料 `students_documents`（匹兹堡大学数字图书馆藏中国契约文书，234 件、407 页，1584–1978，以福建为主）所做的分析。分析基于资料自带的 OCR 文本和 `items.csv` 编目信息，数字均为按关键词统计的下限估计，未逐件核对原图。

## 主要发现

- **土地类型**：以田为主（约 105 件），其次是房屋（43）、宅基地（37）、山地（15）、园地（11）、池塘（8）、坟地（7）。田又分民田、屯田、寺田、祀田、养膳田等，以及田面、田根、根面全、皮骨等不同的权利层次。
- **地理**：闽侯（闽县、侯官、林森）占可定位文书的一半；城市（福州、东山县城）以房屋为主，闽江中游以田为主，闽北、闽西多山地契约。
- **交易方式**：卖 89 件、典 55 件；福州一带典、撥典、凑断最多，闽北、闽西以卖断为主。
- **价格**：闽侯房价从同治年间的十余两涨到民国的数百至一千元；田价没有明显趋势，单价主要取决于权利层次（闽侯田面每亩约 12 元，田根约 74 元，根面全约 57 元，折合银元）。
- **历史背景**：契约中能直接看到太平天国造成的契据遗失、福州钱庄银票和台伏、1913 年和 1928–35 年的验契、战时田赋征实、1947 年土地陈报、1949–52 年改用黄金和大米计价、土地改革等。文书数量的高峰（1913、1947、1951–53）来自政策，不代表交易增多。

## 脚本

`scripts/` 中是生成统计数据的 Python 脚本，按以下顺序运行（`DATA_DIR` 指向 `students_documents` 目录）：

1. `dump.py <DATA_DIR> all.txt`：合并 OCR 文本与编目信息
2. `c2.py`：按关键词判定土地类型（被 `geo.py` 引用）
3. `geo.py`：判定所在县份
4. `tx.py`：判定交易方式
5. `scale.py`、`scale2.py`：提取价格与面积
6. `units.py`：提取计量单位

原始数据（图片、OCR、items.csv）未上传。页面中的部分数据（如闽侯价格、林家个案）在脚本结果基础上做了人工核对和修正，直接写在 HTML 里。

## 局限

- OCR 有错字，关键词统计会漏计或误判。
- 文书在各年代、各地区的多少受收藏来源影响很大，不能直接代表交易的多少。
- 价格折算采用 1913 年验契单上的“申银”比率（1 两 ≈ 1.45 元，1 千文 ≈ 1 元），19 世纪的折算只能看量级。
